# Power BI Dashboards

This folder contains **Power BI dashboard projects** developed to demonstrate practical data analysis and reporting skills aligned with the **PL-300: Microsoft Power BI Data Analyst Associate** certification.

## What this section demonstrates
- Data modeling and relationships
- Creation of measures using DAX
- KPI-driven dashboard design
- Interactive reports with slicers and drill-downs
- Clear visual storytelling for business users

## Structure
Each dashboard is stored in its own folder and includes:
- The `.pbix` Power BI file
- Screenshots of key report pages
- A short description of objectives and insights

## Current Projects
- **Sales Performance Dashboard**
- **Customer Insights Dashboard** (planned)

Dashboards are designed with a focus on clarity, consistency, and business relevance rather than visual complexity.
