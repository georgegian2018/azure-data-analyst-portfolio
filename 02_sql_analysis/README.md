# SQL Analysis

This folder contains **SQL-based data analysis projects** focused on answering real-world business questions using structured queries.

## What this section demonstrates
- Writing clean, readable SQL
- Use of joins, aggregations, and filtering
- Common Table Expressions (CTEs)
- Window functions for analytical queries
- Translating business questions into SQL logic

## Scope
The SQL scripts in this folder are designed to:
- Support insights used in Power BI dashboards
- Validate trends and KPIs
- Perform exploratory and descriptive analysis

Each `.sql` file targets a specific analysis use case and is documented for clarity.
