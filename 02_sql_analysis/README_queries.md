# SQL Queries Overview

This document provides a brief overview of the SQL queries included in this folder and the business questions they address.

## Included Queries

### `sales_analysis.sql`
Focuses on sales performance analysis, including:
- Total revenue and order volume
- Revenue trends over time
- Sales breakdown by product and region
- Average order value

### `customer_retention.sql`
Focuses on customer-related metrics, including:
- Customer lifetime value
- Repeat customer analysis
- Top customers by revenue
- Basic retention indicators

## Notes
- Queries are written using standard SQL syntax
- Minor adaptations may be required depending on the database engine (Azure SQL, PostgreSQL, SQL Server)
- All queries are intended to be understandable and reusable
