# Python Data Analysis

This folder contains **Python-based data analysis notebooks** used for data cleaning, exploration, and validation of analytical results.

## What this section demonstrates
- Loading and inspecting datasets using Pandas
- Data cleaning techniques (missing values, duplicates, outliers)
- Exploratory Data Analysis (EDA)
- Visualisation using Matplotlib
- Reproducible, well-documented notebooks

## Scope
The notebooks in this folder are intentionally focused on:
- Descriptive and exploratory analysis
- Supporting insights used in SQL and Power BI
- Building reusable data cleaning workflows

This section does not focus on machine learning, as the primary goal is to demonstrate strong **data analyst fundamentals**.
