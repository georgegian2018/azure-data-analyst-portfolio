# Azure Data Projects

This folder contains **Azure-focused data projects** that demonstrate how cloud-based data sources integrate with analytics and reporting tools.

## What this section demonstrates
- Understanding of Azure data fundamentals
- Basic cloud data architecture concepts
- Integration between Azure services and Power BI
- Practical application of concepts from AZ-900 and DP-900

## Planned Scenarios
Examples of scenarios that will be implemented here include:
- Azure SQL Database as a data source for Power BI
- Azure Blob Storage for data ingestion
- Simple end-to-end analytics workflows

Projects in this section are designed to remain **simple, realistic, and junior-friendly**, focusing on clarity rather than complexity.
