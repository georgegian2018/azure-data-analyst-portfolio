# Datasets

This folder contains **datasets used across projects** in this repository.

## Dataset Sources
Datasets included in this portfolio are:
- Publicly available datasets
- Open-license datasets
- Synthetic datasets created for demonstration purposes

## Usage Guidelines
- Each dataset is used strictly for educational and portfolio purposes
- Licensing and source information will be documented where applicable
- Large datasets may be excluded and referenced via download links instead

## Structure
Datasets are organised by project or topic to ensure clarity and reusability.

## Notes
If a dataset cannot be redistributed due to licensing restrictions, instructions will be provided on how to obtain it independently.
